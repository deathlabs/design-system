# Deathlabs Design System

This repository contains shared standards, examples, and implementations for Deathlabs products.

## Repository Structure

* `docs/`: Design standards, product guidelines, and development practices
* `examples/`: Runnable examples that demonstrate the design system
* `terminal/`: Terminal design-system direction and future implementation
* `web/`: The `@deathlabs/design-system` React and Material UI package

## Development

Install the web package and example dependencies:

```bash
make setup
```

Run checks, tests, or the web example:

```bash
make check
make test
make dev
```

See [the web package documentation](web/README.md) for package usage and [the documentation index](docs/README.md) for design guidance.
